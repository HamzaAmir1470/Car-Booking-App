# 🚗 Car Booking App

A modern, cross-platform mobile application built with React Native and Expo that allows users to seamlessly explore, compare, and book rental vehicles.

---

## 📸 Features

- **Vehicle Catalog:** Browse available cars with details on specs, pricing, and availability.
- **Interactive Booking:** Select rental dates, times, and pickup locations.
- **User Authentication:** Secure signup/login flow for managing reservations.
- **Booking Management:** View active, upcoming, and past rental history.
- **Responsive UI:** Clean, intuitive interface tailored for iOS and Android devices.

---

## 🛠️ Tech Stack

- **Framework:** React Native
- **Tooling:** Expo SDK
- **Navigation:** React Navigation / Expo Router
- **Language:** JavaScript / TypeScript
